# ⚙️ OficinaPro

O **OficinaPro** é um sistema em **Java** para gerenciar ordens de serviço de oficinas mecânicas. Ele foi criado para aplicar na prática os quatro pilares da Programação Orientada a Objetos (POO): **Abstração, Herança, Encapsulamento e Composição**. 

O programa roda no terminal e possui um menu interativo que cadastra clientes e calcula dinamicamente o valor da mão de obra de forma personalizada (aplicando taxas extras para carros com ar-condicionado ou motos de alta cilindrada).

O projeto foi estruturado com Maven para, no futuro, evoluir para uma **API REST** completa com **Spring Boot** e banco de dados.
